# آموزشگاه موسیقی هاشم شکیبا

لندینگ فارسی و راست‌به‌چپ، با گیتار سه‌بعدی تعاملی، نوشتهٔ نستعلیق و تم قهوه‌ای و سفید گرم.

## اجرا

محتویات پوشه را روی یک میزبان استاتیک با HTTPS قرار دهید. نقطهٔ ورود `index.html` است؛ مرحلهٔ build یا سرور اختصاصی لازم نیست. این نسخه در پیش‌نمایش آمادهٔ استفاده است، اما روی دامنهٔ عمومی منتشر نشده است.

برای اجرای محلی: `python3 -m http.server 8080` و سپس بازکردن `http://localhost:8080`.

## فایل‌ها

- `index.html`: ساختار و محتوای فارسی
- `styles.css`: طراحی واکنش‌گرا
- `guitar.js`: مدل دست‌ساز Three.js، نورپردازی، تشخیص سیم و فرت، لرزش سیم و چرخش
- `audio.js`: سمپل صوتی، پردازش رنگ صدای سیم‌ها و مدل‌سازی جایگزین
- `app.js`: کنترل‌های صفحه، آرپژ نمونه، راهنما و کلیدهای میان‌بر

## نواختن

ابتدا «شروع نواختن» را بزنید. روی سیم‌ها حرکت کنید یا سیم و فرت را لمس کنید. پنل نت‌ها امکان انتخاب دقیق فرت آزاد تا ۱۹ و نواختن هر شش سیم را می‌دهد. کلیدهای ۱ تا ۶ سیم‌ها و جهت چپ و راست فرت انتخاب‌شده را کنترل می‌کنند.

۱۲۰ ترکیب سیم/فرت بر مبنای کوک استاندارد پشتیبانی می‌شود؛ همانند ساز واقعی، بعضی ترکیب‌ها نت یکسان دارند. رنگ صدا بر اساس سیم و فرت تنظیم می‌شود؛ نمونه‌ها ضبط جداگانه از تک‌تک موقعیت‌های یک ساز اختصاصی نیستند.

## وابستگی‌های اینترنتی و اعتبارها

- Three.js 0.160.1 — https://threejs.org/
- Vazirmatn — https://github.com/rastikerdar/vazirmatn
- Noto Nastaliq Urdu — https://github.com/google/fonts/tree/main/ofl/notonastaliqurdu
- FluidR3 GM nylon guitar / MIDI.js Soundfonts — https://github.com/gleitz/midi-js-soundfonts

کتابخانه، فونت‌ها و سمپل‌ها از jsDelivr بارگذاری می‌شوند. در نبود سمپل، صدای مدل‌سازی‌شده جایگزین می‌شود. برای میزبانی مستقل، وابستگی‌ها را با حفظ مجوزها و اعلان‌های صاحبان اثر به‌صورت محلی میزبانی کنید.

اطلاعات دوره‌ها، تماس و ثبت‌نام هنوز ارائه نشده و ساخته نشده است.
